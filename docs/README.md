# 文档目录

本目录包含项目的重构计划、诊断报告和 AI 工作指南。

## 文件说明

| 文件 | 说明 |
|------|------|
| `整改计划.md` | 详细的重构实施方案，分为 Phase 1-4，共 4 个阶段 |
| `AI工作文档.md` | AI Agent 工作指南，包含任务领取流程、工作报告模板、代码规范 |
| `诊断1.md` ~ `诊断5.md` | 五份代码诊断报告，是整改计划的依据 |

## 快速开始

新来的 AI Agent 请按以下顺序阅读：

1. `AI工作文档.md` 的"快速启动"章节
2. `整改计划.md` 的"六、重构顺序建议"
3. 对应 Phase 的具体任务章节

## 关于本目录

- `整改计划.md` 和 `AI工作文档.md` 是权威真相来源
- 任何 Agent 都应从 GitHub 仓库拉取最新版本
- 不要在本地创建与仓库平行的"第二套"文档体系
