## 核心代码改动说明

### HardwareConfig.h

将 Python 版的 `CameraConfig` / `RadarConfig` / `AprilTagConfig` 三个类翻译为 C++ 静态结构体，数值完全对齐：
- `CameraConfig::kFX()` / `kFY()` 使用 `constexpr` 表达式计算，与 Python 等价
- `RadarConfig` 包含雷达外参（delta_x/y/z）、相机俯仰角、高度等
- 提供 `make_camera_params()` 工厂函数，生成与 Python 版 `camera_params` tuple 等价的 `CameraParams` 结构体

### SceneConfig.h/.cpp

核心类：
- **`SceneConfigLoader`**：纯 YAML 解析器，从 `scene.yaml` 加载 colors/morphology/clahe/detection 四个字段，提供 `load()` / `load_default()` 静态方法
- **`GlobalSceneConfig`**：线程安全的单例，程序启动时自动加载 `config/scene.yaml`，加载失败时回退内置默认值；`reload()` 方法支持热重载

关键设计：
- `colors` 字段解析：遍历 YAML map，将 `lower`/`upper` 数组转为 `cv::Scalar`
- 默认值回退：任何解析失败都使用内置默认值，保证程序不会崩溃
- `last_path_` 成员：`reload()` 依赖此字段避免硬编码路径 bug

### Protocol.h

将 Python 版的 `IDX_*` / `FIELD_OFFSETS` / `FIELD_WIDTHS` 翻译为：
- `ProtocolFieldIdx` namespace：36个偏移量常量（`kHeader=0` 到 `kChecksum=35`）
- `ProtocolFieldWidth` namespace：各字段宽度常量
- `unpack_int16_le/be()` / `pack_int16_be()` 工具函数：处理大小端字节序
- `compute_protocol_checksum()`：累加前35字节取低8位，与 Python 版完全一致

### CMakeLists.txt 修改

为支持 MSYS2 环境（非 Conan）做了以下修改：
1. Conan 检测改为可选（`if(EXISTS ...)` 包裹）
2. 添加 `MSYS2_PREFIX` 路径（`C:/msys64/mingw64`）
3. 修复 `CMAKE_POLICY_VERSION_MINIMUM` 语法错误（改为 `CMAKE_VERSION VERSION_GREATER_EQUAL`）
4. Debug 模式 sanitizer 库缺失问题：通过 `-DENABLE_SANITIZERS=OFF` 规避

## 功能等价性验证

- **YAML 解析**：Python 读取 `config/scene.yaml` 的 colors/morphology/detection 字段；C++ 版通过 `SceneConfigLoader::load()` 解析相同文件，结构完全对应
- **默认值**：`default_hsv_thresholds()` 与 Python 版 `scene.yaml` 中的初始值逐颜色对比一致
- **协议偏移**：`ProtocolFieldIdx::k*` 与 Python 版的 `IDX_*` 逐个对比一致
- **相机参数**：`make_camera_params()` 计算的 fx/fy/cx/cy 与 Python 版 `CameraConfig` 完全一致

## 与 Python 版的关键差异记录

无实质性差异。以下为实现方式差异（不影响功能）：

1. Python 使用类属性 `CameraConfig.FX`，C++ 使用 `static constexpr float kFX()` 成员函数（返回值等价）
2. Python 的 `yaml.safe_load()` 自动处理类型，C++ 使用 `YAML::Node::as<T>()` 并提供默认值
3. Python `camera_params = (fx, fy, ...)` 是 tuple，C++ 使用 `CameraParams::to_array()` 返回 `std::array<float, 10>`
4. C++ 配置层分为两层：`SceneConfigLoader`（纯解析器）和 `GlobalSceneConfig`（单例+默认值），Python 只有一层 `SCENE` 字典
