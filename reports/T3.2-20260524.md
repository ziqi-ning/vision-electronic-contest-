## 核心代码改动说明

### 新建 `src/utils/logger.py`

提供全项目统一的日志接口，核心设计：
- **单例模式**：每个模块名称（`__name__`）只创建一次 handler，避免重复输出
- **级别分类**：按 DEBUG/INFO/WARNING/ERROR 四级分类，与整改计划一致
- **便捷 API**：`get_logger(name)` 复用已注册 Logger

```python
from src.utils.logger import get_logger
logger = get_logger(__name__)
logger.info("serialport init: %s @ %s", port, baudrate)
```

### 各文件替换策略

| 原 print 内容 | 替换为 | 级别 |
|--------------|--------|------|
| `print("Cannot open camera")` | `logger.error(...)` | ERROR |
| `print("serialport init fail")` | `logger.error(...)` | ERROR |
| `print("serialport init: ...") ` | `logger.info(...)` | INFO |
| `print("serial has been ready")` | `logger.info(...)` | INFO |
| `print("校验完毕，模式码是：...")` | `logger.info(...)` | INFO |
| `print("serial buf :...")` | `logger.debug(...)` | DEBUG |
| `print("[INFO] Found barcode: ...")` | `logger.info(...)` | INFO |
| `print("Decoded Data: ...")` | `logger.info(...)` | INFO |
| `print("Error: Image not loaded")` | `logger.error(...)` | ERROR |
| `print("midle_area: ...")` | `logger.debug(...)` | DEBUG |
| `print(f"Obstacle: ...")` | `logger.debug(...)` | DEBUG |
