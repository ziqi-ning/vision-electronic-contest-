```yaml
colors:

    lower: [0, 43, 46]
    upper: [10, 255, 255]

    lower: [35, 43, 46]
    upper: [77, 255, 255]
  # ... 其他 10 种颜色

  erode_iter: 2
  dilate_iter: 2

  min_area: 1200
  roi_bais: 20
```

### 2. 改造调参工具

新增导入 + 路径定义：
```python
import yaml, os
CONFIG_YAML_PATH = os.path.join(os.path.dirname(__file__), "..", "config", "scene.yaml")
```

新增导出函数：
```python
def on_export(x):
    _update_current_values()  # 读取所有 trackbar 当前值
    config = {
        "colors": {"red": {"lower": _current_lower, "upper": _current_upper}},
        "clahe": {"clip_limit": _current_clip_limit},
        ...
    }
    with open(CONFIG_YAML_PATH, "w", encoding="utf-8") as f:
        yaml.dump(config, f, allow_unicode=True, ...)
    print("[调参工具] 参数已导出")
```

新增导出按钮（在 hsv 窗口）：
```python
cv2.createButton("导出参数到 scene.yaml", on_export, None, cv2.QT_PUSH_BUTTON, 0)
```
