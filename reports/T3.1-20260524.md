## 核心代码改动说明

### 1. 抽象基类设计 (`src/radar/base.py`)

```python
class RadarSource(ABC):
    @abstractmethod
    def is_available(self) -> bool: ...

    @abstractmethod
    async def get_scan(self) -> Optional[RadarScanResult]: ...
```

所有雷达数据源（ROS / 模拟 / 文件等）均实现此接口，上层 `RadarFusion` 不感知具体实现。

### 2. Lazy Import ROS (`src/radar/ros_source.py`)

```python
def _try_import_ros():
    try:
        sys.path.append('/opt/ros/noetic/lib/python3/dist-packages')
        import rospy
        from sensor_msgs.msg import LaserScan
        ...
        _ROS_AVAILABLE = True
    except (ImportError, ModuleNotFoundError):
        _ROS_AVAILABLE = False
```

仅在 ROS 环境存在时才加载 `rospy`，避免无条件导入导致 Windows / 无 ROS 环境崩溃。

### 3. 自动数据源检测 (`src/radar/fusion.py`)

```python
def _auto_detect_source(self) -> RadarSource:
    if ros_available:
        ros_source = ROSRadarSource()
        if ros_source.is_available():
            return ros_source
    return SimRadarSource()  # ROS 不可用时回退到模拟数据源
```

`RadarFusion()` 不传参数时自动检测可用数据源，优先 ROS，失败则回退模拟。

### 4. 接口兼容 (`main.py`)

```python
# 修改前：try/except 包裹导入
try:
    import src.radar5 as radar5
    radar = radar5.RadarManager()
except Exception:
    radar = None

# 修改后：直接使用 RadarFusion
from src.radar import RadarFusion
radar = RadarFusion()
```

上层 `idle_mode.py` 调用方式不变（`self.radar.site_to_distance()` 等），`RadarFusion` 接口与原 `radar5.RadarManager` 完全兼容。
