# 工作报告目录

每次完成一个子任务后，将工作报告写入本目录。

## 文件命名规则

```
T{Phase编号}.{子任务编号}-{日期}.md
```

例：
- `T1.1-20250601.md` — Phase 1, 子任务 1, 2025年6月1日完成
- `T2.3-20250615.md` — Phase 2, 子任务 3, 2025年6月15日完成
