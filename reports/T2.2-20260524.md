## 核心代码改动说明

### roi_extractor.py

将 `allin.py` 中 5 个独立的 `color_bonous_*` 函数抽象为策略模式：

```
ROIExtractor (ABC)
├── CircleROIExtractor    → 对应 color_bonous_usual / give_me_a_color...
├── RectROIExtractor      → 对应 detect_color_to_rect 变体
├── ORBROIExtractor       → 对应 color_bonous_ORB（含椭圆边缘模糊）
├── LineROIExtractor     → 对应 color_bonous_for_line（含直线检测）
├── MultiColorROIExtractor → 对应 color_bonous_multi_color
└── LaserROIExtractor    → 对应 color_bonous_laser_small_area
```

同时提取了 `blur_contour_only()` 和 `composite_ROIs()` 工具函数。

### shape_classifier.py

将 `allin.find_type()` 中的 4 段 `if mode == N` 级联逻辑封装为 `ShapeClassifier`：

- 可配置优先级顺序（默认 trapezoid → triangle → pole → ellipse）
- 每个检测器注册到 `_registry` 字典，支持扩展
- 返回 `List[DetectionResult]`，与 Phase 2 T2.1 的统一类型系统对接

### orchestrator.py

`DetectionPipeline` 将原 `give_me_a_color_and_i_will_give_you_a_shape()` 的完整逻辑重组：

1. 调用 `roi_extractor.extract()` 获取 ROI 列表
2. 对每个 ROI 调用 `shape_classifier.classify()` 检测形状
3. 按 `filled_mask` 机制合成图像（防止重叠区域重复填充）
4. 返回 `type_list`（与原函数格式完全一致）和 `composite_img`
