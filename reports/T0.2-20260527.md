### src/Types.cpp

- `CameraParams::from_hardware_config()`：使用 `Version.h` 中的默认值构造完整参数
- `TargetData::compute_checksum()`：`sum(data[0..34]) & 0xFF`，与 Python 版 `uartuse.py` 逐字节一致
- `default_hsv_thresholds()`：12种颜色的 HSV 上下界，默认值（Python YAML 待 T0.3 加载）

## 与 Python 版的关键差异记录

- C++ 中用 `std::optional<T>` 替代 Python 的 `Optional[T]` 和 `None`
- `DetectionResult.extra` 使用 `cv::Variant`（OpenCV 内置，支持 `int/double/string/Vec3` 等）
- `TargetData` 的校验和由 `compute_checksum()` 方法计算，而非 Python 中的裸 `sum(data[:-1]) & 0xFF`
- `RadarScan.obstacles` 初始化为空 `vector`，与 Python 的 `field(default_factory=list)` 等效

## 遗留问题

- `cv::Variant` 在 OpenCV 某些版本中行为可能不同，需在 T0.5 或 T5.1 补充单元测试验证
